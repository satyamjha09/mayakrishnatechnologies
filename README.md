# Mayakrishna Technologies — Next.js + Tailwind

A componentized Next.js App Router conversion of the supplied single-file HTML page.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Structure

- `components/IntroAnimation.tsx` — timed 6.5-second intro and skip behavior
- `components/MayakrishnaLanding.tsx` — landing page and product cards
- `app/globals.css` — exact keyframes and texture animation
- `public/` — extracted logos and original SVG card artwork
